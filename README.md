**Начните со страницы-карты:** https://lavnikovich.github.io/career-map/

Там короткий ответ, три трека на ближайший месяц, шесть сценариев со сравнением, план до 2029 года, нестандартные треки, бизнес, Италия, упаковка услуг и чек-лист.

## Как читать

- **Метки:** **[Ф]** — факт из источника (ссылка и дата рядом), **[О]** — оценка, **[Г]** — гипотеза, которую нужно проверить на практике.
- **Срез данных — 17.11.2026.** Вакансии быстро закрываются, перед откликом проверьте ссылку.
- **Зарплаты** указаны на руки, если не написано иное. Выборки по нишевым ролям маленькие, медианы — ориентир, а не статистика.
- **Цены на собственные услуги** — гипотезы, их проверяют на первых переговорах.
- Имена и личные данные из исходных материалов убраны.
